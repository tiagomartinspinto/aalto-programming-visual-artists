Variables, Mouse Input and Mapping

Use this session to see how a named value that changes every frame can drive color, position, and interaction.

Before class

Open and move

Open Mouse Shapes and move the pointer to see what changes. Nothing else to prepare.

During class

Change one thing

Run it, replace a fixed number with mouseX or mouseY, read any error you cause, repair it, then combine two changes.

After class

Keep your composition

Save your own responsive composition. Write down one thing you understand about map() and one thing you still don't.

Start in the Browser

Open Color House first for one clear click-to-change variable, then Mouse Shapes for continuous mouse-driven variables.
