Aalto University

Conditionals, Movement and State

Last session, the mouse changed values for you. Now the sketch changes its own position every frame, and if decides what happens next.

Before class

Open and watch

Open Bouncing Ball Color and watch it move and bounce for a minute. Nothing else to prepare.

During class

Change one thing

Run it, change the speed or the edge reaction, then cause the wrong-variable mistake on purpose, notice the behavior is wrong with no error message, and fix it.

After class

Keep your composition

Save a moving composition that feels like your own. Write down one condition in your sketch and what it controls.

Start in the Browser

Open Hover Color first for one shape and one condition, then Bouncing Ball Color for movement, edges, and state.
