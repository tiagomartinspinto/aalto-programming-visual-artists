Loops, Grids and Waves

Last session, one ball changed frame after frame. Now one block of code creates many shapes without writing the same drawing command again and again.

Before class

Open and count

Open Loop Row and count the circles. Nothing else to prepare.

During class

Change one thing

Run each sketch, change a loop count or spacing, then mix up a row/column calculation on purpose, notice the grid distorts with no error message, and fix it.

After class

Keep your composition

Save a repeated or wave-based composition that feels like your own. Write down what one loop in your sketch controls.

Start in the Browser

Open Loop Row first for one loop making one row, then Hover Grid for two loops making a grid that reacts, then Simple Waves for sin() turning repetition into rhythm.
