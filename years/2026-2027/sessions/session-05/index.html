Functions, Parameters and Generative Systems

Last session, loops repeated a drawing instruction many times. Now we package a visual rule inside a function and change what it draws just by giving it different parameter values - the same idea as drawFace(x, y, diameter) in Session 01, used deliberately this time.

Before class

Open and regenerate

Open Shapes Function and click it a few times. Nothing else to prepare.

During class

Change one thing

Run it, change a parameter or a random range, then add a new parameter and forget to use it inside the function - notice nothing changes until you fix that - and combine two changes.

After class

Design your system

Save a version of the shape system that feels like your own generative rule. Write down which parameter controls which visual result.

Start in the Browser

Shapes Function is the required exercise: one reusable function, called many times with random parameters, building a whole composition.
